# Coconect

Сервис ужинов для основателей и предпринимателей: люди проходят онбординг в
WhatsApp, система собирает профиль, рассаживает гостей по столам и ведёт их
через весь цикл ужина — от приглашения до фидбека.

Это **публичная версия репозитория**. Часть кода из неё вырезана намеренно —
см. [Что вырезано](#что-вырезано).

## Стек

| Слой | Технологии |
|---|---|
| Бэкенд | Python, FastAPI, Supabase (Postgres), Pinecone |
| LLM | Google Gemini (извлечение профиля, диалог онбординга) |
| Мессенджер | WhatsApp Cloud API (Meta) |
| Голос | Vapi |
| Фронтенд | Next.js, TypeScript, Tailwind |
| Инфра | Docker Compose, Caddy |

## Структура

```
ai-engine/          FastAPI-бэкенд
  main.py           основные HTTP-ручки
  wa/               WhatsApp: вебхук, диалог, lifecycle ужина, отправка
  matching/         рассадка по столам (см. «Что вырезано»)
  llm_extract.py    извлечение профиля и генерация текстов через LLM
  scraper/          импорт профиля из LinkedIn
  admin_routes.py   админка
web-app/            Next.js-фронтенд
infrastructure/     схема Supabase и миграции
```

## Запуск

```bash
# 1. Бэкенд
cd ai-engine
cp .env.example .env         # заполнить своими ключами
pip install -r requirements.txt
python run.py

# 2. Фронтенд
cd web-app
npm install
npm run dev

# 3. База: применить infrastructure/supabase_schema.sql,
#    затем миграции из infrastructure/migrations/ по порядку.
```

Для локальной работы без ключей LLM поставьте `IMITATION_MODE=true` — эмбеддинги
и вызовы модели заменятся моками.

## Что вырезано

Публичная версия не содержит проприетарную часть и любые персональные данные.
Убрано осознанно, а не по недосмотру:

**Алгоритм матчинга.** Файлы `matching/scoring.py`, `matching/assembler.py`,
`matching/rerank.py` оставлены как заглушки: сигнатуры и докстринги на месте,
формулы, веса и калибровка — нет. Код импортируется и запускается, но рассадка
получается наивной (гости нарезаются подряд). Чтобы поднять форк, реализуйте эти
функции своей логикой.

**Промпты к LLM.** Тексты инструкций для модели в `llm_extract.py` и
`voice_agent.py` заменены на `_REDACTED_PROMPT`. Структура пайплайна, разбор
ответа и обработка ошибок сохранены.

**Данные.** Кэш распарсенных LinkedIn-профилей, выгрузки пользователей, отчёты
матчинга, фото участников и продовые логи не входят в репозиторий. Фотографии в
`web-app/public/photos/` заменены на серые плейсхолдеры, папка
`web-app/public/videos/` пуста — лендинг соберётся, но будет без медиа.

**Секреты.** Ключей в репозитории нет. Все значения берутся из окружения,
шаблон — `ai-engine/.env.example`. Админка (`/admin/*`) без заданных
`ADMIN_LOGIN` / `ADMIN_PASSWORD` / `ADMIN_TOKEN` отвечает 503: дефолтных
кредов нет намеренно.
